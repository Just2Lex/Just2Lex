# Alexey Dzusov  
**Minecraft Plugin Developer (Hobbyist)**

---

## About

I am a graduate with a background in network technologies and system administration.  
My primary spare‑time activity is developing plugins for Minecraft servers using the Paper/Bukkit API.  
This hobby allows me to deepen my Java programming skills and practice designing maintainable, game‑oriented software.

---

## Skills & Technologies

- **Languages:** Java (primary), basic Kotlin.  
- **Frameworks & APIs:** Paper, Bukkit, Spigot.  
- **Tools:** Git, GitHub, IntelliJ IDEA, Gradle.  
- **Operations:** Fundamental knowledge of Linux server configuration and network protocols.
