## 👤 About Me

I am a graduate with a background in network technologies and system administration.  
My primary spare‑time activity is developing plugins for Minecraft servers using the Paper/Bukkit API.  
This hobby allows me to deepen my Java programming skills and practice designing maintainable, game‑oriented software.

## 📦 Projects

| Project | Description | Stack |
|---------|-------------|-------|
| [**LexCase**](https://github.com/Just2Lex/LexCase) | Crate system with holographic displays, reward draws, and a luck/debt mechanic. | Paper 1.21.11, Java |
| [**Quest-Engine**](https://github.com/Just2Lex/Quest-Engine) | Modular quest engine for creating and managing server‑side quests. | Paper 1.21.11, Java |
| [**spawnify**](https://github.com/Just2Lex/spawnify) | Advanced spawn system with world‑specific spawns, personal points, GUI selection, teleport delays, and cooldowns. | Paper 1.21.X, Java |
| [**RepMe**](https://github.com/Just2Lex/RepMe) | Lightweight reputation plugin allowing players to rate each other and leave comments via a paginated GUI. | Paper/Bukkit, Java |
